# Student Performance Analysis System

## Project Overview

This project analyzes the academic performance of students using Python, NumPy, and Pandas.

## Technologies Used

* Python
* NumPy
* Pandas
* Google Colab / Jupyter Notebook

## Dataset

The dataset contains 5 students, 3 subjects, and attendance information.

## Features

* Calculate total and average marks
* Assign grades based on average marks
* Identify pass and fail students
* Find the highest and lowest performing students
* Calculate subject-wise average marks
* Identify the top 3 students
* Generate a final student performance report

## How to Run

1. Download the notebook and CSV dataset.
2. Upload both files to Google Colab.
3. Run the notebook cells in order.

## Learning Outcomes

This project demonstrates Python functions, loops, NumPy numerical calculations, and Pandas DataFrame operations.
